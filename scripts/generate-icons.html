Générateur d'icônes PWA — CABBA

Le manifeste référence icon-192.png et icon-512.png. Cette page les produit à partir de la même source vectorielle que public/icon.svg, sans installer de dépendance.

  1. Clique sur le bouton ci-dessous : les deux fichiers sont téléchargés.
  2. Déplace-les dans public/, à côté de icon.svg.
  3. Relance npm run build.

Le « C » occupe moins de 60 % du canvas : l'icône reste correcte une fois rognée en cercle par Android (purpose: "any maskable"). Si tu obtiens le logo officiel du club, remplace simplement ces PNG en gardant les mêmes noms et tailles.
